## Resumo dos Conceitos Praticados

Durante a resolução destes módulos, o foco foi a construção de uma base sólida para o desenvolvimento back-end e infraestrutura. O processo iniciou-se com a manipulação do sistema operativo via terminal usando Bash, o que facilita a automatização e o controlo do ambiente de desenvolvimento. Em seguida, as práticas aprofundaram-se na estruturação e persistência de dados utilizando bases de dados relacionais com PostgreSQL. Paralelamente, iniciei a lógica de programação do lado do servidor utilizando Node.js e compreendendo a função dos seus módulos principais.

As principais dificuldades envolveram geralmente a adaptação inicial à interface puramente em texto do Bash e a sintaxe relacional rígida na hora de vincular chaves estrangeiras no PostgreSQL. As estruturas e comandos mais utilizados incluíram comandos de navegação e diretórios (`cd`, `ls`, `mkdir`) no Bash, instruções DDL e DML (`CREATE TABLE`, `INSERT`, `SELECT`) para a gestão de dados em SQL, e funções de importação de módulos (`require()`) na construção das APIs em Node.js.
